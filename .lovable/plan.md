
# Chamber 03 — Scenario Engine v3 ("What if…" Studio)

## Why the current build fails users
Testers said Chamber 03 is intimidating. Concretely, `countries.$code.scenarios.new.tsx` is a 707-line multi-panel workbench (GuidedRail 571 lines, LeversDrawer + LeverRowV2, PlaybookChips, Compensation Ledger, Sensitivity, Tornado, Attribution, AI Recommend Drawer, Compare Slots…) all shown at once. Ministers see 12 dense modules, macro jargon (elasticity, compensation, attribution stack, tornado), and no obvious first move. Empty state is a link to a wall.

The redesign inverts the model: **one question at a time, plain English, always-on preview, expert depth on demand**.

## The new experience — a 3-screen journey

**Screen 1 — Ask a question (Concierge-style intake)**
- Single centered card: "What decision are you weighing?"
- Three ways to start, big tap targets:
  1. **Pick a common Caribbean question** (chips) — e.g. *"What if tourism drops 20%?"*, *"What if we cut fuel duty?"*, *"What if a hurricane hits Q3?"*, *"What if we grow BPO by 10%?"*, *"What if remittances fall?"*. Each chip is a curated preset from `scenarios/playbooks.ts` reframed in minister language.
  2. **Type it in plain English** — one line, e.g. "raise minimum wage to $9". An AI intake (reuses `recommend-scenario.functions.ts` + `synthesize-levers.functions.ts`) parses it into a draft scenario with levers pre-populated.
  3. **Voice it** — mic button (reuses `useVoiceRecorder` from Persona Lab / Concierge) → same AI intake pipeline.
- No forms, no dropdowns, no lever picker on this screen.

**Screen 2 — See the ripple (single-page result)**
Split 60/40, mobile stacks:
- **Left ("The story")** — headline in plain English generated by AI: *"If tourism arrivals fall 20% over 12 months, real GDP is ~2.1% lower by 2027, ~4,200 jobs at risk, fiscal deficit widens by 1.3% of GDP."* Three bullets: **What happens**, **Who feels it first** (ministries/sectors), **What could offset it**. Everything cites second-brain sources via existing `CitationsRail` pattern.
- **Right ("The picture")** — one large `GdpFanChart` (already built) + a small sector waterfall (existing `SectorWaterfall`) beneath. No tornado / sensitivity / attribution by default.
- **Bottom action bar (sticky, mobile-first)**: **Adjust** · **Compare** · **Send to Cabinet** · **Save**.

**Screen 3 — Adjust (progressive disclosure)**
- Adjust opens a right-side sheet with **only the 2–4 levers that actually drive this scenario**, each rendered as a labeled slider with plain units ("Tourism arrivals: −20% ← → +20%", "Fuel duty: $0.00 → $0.75/gal"). Live preview redraws the fan chart and headline as they drag. Debounced local engine (`local-engine.ts`) so it feels instant; server recomputes ripple on release.
- A single "Show all levers" link reveals the full LeversDrawer for power users — off by default.
- Expert modules (Tornado, Sensitivity, Compensation Ledger, Attribution Stack) move to a collapsed **"Analyst view"** toggle in the header — hidden for ministers, one click for advisors.

## Cross-chamber wiring (make it useful, not just pretty)
- **Send to Cabinet** creates a Chamber 06 decision item (existing `cabinet.functions.ts`) with the scenario snapshot + headline + fan chart PNG.
- **Send to Narrative** hands the plain-English story to Chamber 05 as a strategy statement seed.
- **From Chamber 08 (Mandate Compact)**: each pledge gets a "Stress-test this pledge" button that opens Screen 2 pre-loaded.
- **From Chamber 01 (Ledger)**: any KPI card gets "What if this changed?" that seeds Screen 1.

## Guardrails and quality
- Every result screen shows a plain-English **confidence line** ("Modeled on X sources, updated Y") plus a "How was this calculated?" link opening the current `WhyThisNumberPanel` — trust without jargon.
- Playbooks library (`scenarios/playbooks.ts`) is re-curated for Caribbean SIDS: tourism shock, hurricane, oil price, remittance shock, cruise-fee change, BPO expansion, CBI policy change, VAT change, minimum-wage change, climate-adaptation spend.
- Copy pass: strip words like *elasticity, tornado, compensation ledger, attribution stack*. Replace with *"how sensitive", "biggest movers", "offsets", "what drove the change"*.

## Delivery order
1. **Slice A — Screen 1 (Ask)** + Caribbean playbook chips + AI intake wired to existing `recommend-scenario` / `synthesize-levers`. Ship behind default route.
2. **Slice B — Screen 2 (Story + Picture)** with `plain-story.functions.ts` and reused `GdpFanChart` / `SectorWaterfall`.

4. **Slice D — Send to Cabinet / Narrative hooks + Save + Compare (2-up using existing `CompareSlots`).**

6. **Slice F — Cross-chamber seeds** from Mandate Compact pledges and Ledger KPIs.

## Success criteria
- A minister can go from landing on `/scenarios` to a readable, cited answer in **≤ 15 seconds and 2 taps**.
- Zero macro-econ jargon on the default surface (verified by copy audit).
- Adjust sheet redraws the fan chart in < 200ms on drag (local engine).
- Every result has a clickable citation to the second brain and a one-click handoff to Cabinet or Narrative.
- Analyst view is one toggle away for advisors — nothing lost, just hidden.
